投资A股的朋友们都知道，A股是地狱难度，因此本人总结出来一个规律，通过每次大盘的波动，买卖主要宽基ETF获利。
怎么观察大盘的波动，以全A市场总市值880001为标准（只用这个指标，不要用其他的）。波动上下限为[上年官方GDP*80%*（1-当年官方目标GDP增速），上年官方GDP*80%*(1+当年官方目标GDP增速)]。
举例：以2026年为准，官方公布的2025年GDP是140.19万亿元人民币，2026年官方目标GDP增速为4.5%-5%（根据2026年《政府工作报告》，2026年官方设定的GDP增速预期目标为 4.5%—5%，并强调“在实际工作中努力争取更好结果”。），我们这里取5%，那么计算的上下限为【106.54万亿元，117.76万亿元】。
当880001接近或者小于下限时，买入主要宽基ETF，比如沪深300、创业板、科创50；
当880001接近或者大于上限时，卖出主要宽基ETF。
以后年份的上下限参考值以此类推。
